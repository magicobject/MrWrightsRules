An internal changelog: every build number and what changed. This page isn't linked from anywhere else on the site.

Current build: 2026.10.21.001

  • 2026.10.21.001Greg Wright21 October 2026

    Behind the scenes, no change to what visitors see: the build number no longer appears in every page's footer, and the stylesheet/script links no longer carry it as their cache-busting ?v= value. Every page used to change on every single commit purely because that shared number was stamped into it, even when nothing on the page itself had moved. The build number now only appears on this page, and ?v= is a hash of the actual file's content, so a page's HTML only changes when something it really loads has changed.
